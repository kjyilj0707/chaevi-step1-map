## 화면 단계 추가 규칙 (2026-11-22 최종 점검)
- 화장실 '지금 열림' 필터: 개방시간 문자열(상시, HH:MM~HH:MM, 익일, 평일·주말·토요일 등)을 읽어 지금 요일·시각에 닫힌 화장실은 추천 카드 후보에서 뺌(`reco.js` `R.parseOpen`·`R.openState`, 목록·지도에는 그대로 보임). 못 읽는 표기(정시(영업시작~종료)·기타·'9시간'·빈칸 등)는 카드에 "개방시간 확인". 심야 '상시만' 규칙은 그대로. 공원 파일에는 출입 허용시간 칸이 없어 적용 안 함
- 이 필터는 기준 코드 `score_reference.py`에 없는 화면 단계 규칙임. `RECO.recommend`에 `now`를 넘기지 않으면 꺼지고, 꺼진 상태에서 기준 코드와 같은 결과(대조 시 now 없이 비교)
- 동승자 기능 제외(팀 결정 "동승자 추천 및 고려는 제외"): 정보 입력 3문항(Q4 없음), 추천 화면 동승 칩·결과 태그 없음, `tables.json`의 kid·pet·group 상황 규칙은 화면이 켜지 않음(예전 저장값 q4도 무시)
- 정보 입력 '다시 입력'에서 건너뛰기 = 기존 프로필 유지. 첫 실행의 건너뛰기만 P2 기본값

## 화면 구조 v2 (2026-11-22, 준엽 요청)
- 서울만: 오른쪽 '전국' 버튼·'전국 추세' 탭 삭제. 예전 '읽을 때 주의'는 MY 화면 맨 아래 '이 지도에 대해'

  - 충전 습관 Q1~Q3(예전 규칙), 기본 정보(나이대·성별·거주 구·차종 군·주로 쓰는 충전기·배터리 용량·시간대·빈도), 현재 페르소나·직접 바꾸기·초기화
  - 시작 점수(prior_v1): `start = 3·[Q2] + 1.5·[Q2 없을 때 Q1] + π`, π = normalize(base × 시간대·충전 방식·차종 군 배수 × clip(나이 × 성별, 0.8~1.3)). 표 `data/reco/prior_v1.json` = `../analysis/demo_persona_link/prior_v1.json` 복사(기준 `build_prior.py` score()). 카드 클릭 +1/n은 `learn`에 더함. 거주 구·빈도는 저장만
- 추천 조건 줄(페르소나·남은 시간·날씨 칩)은 숨김: 페르소나 = MY, 남은 시간 = 충전 타이머(돌 때, 실제 남은 분 — 아래 '남은 시간 = 실제 분') 또는 MY '보통 머무는 시간', 날씨 = 지금. 리스트 아래 작은 글로 기준 표시
- 지도: '지금 충전하기 좋은 곳' 상위 3곳 아이콘이 통통 튀고 '1순위~3순위' 말풍선(HTML 표시, prefers-reduced-motion이면 정지)
- 충전소 상세 탭 '주변 | 지금 충전소'
  - 주변: 페르소나 슬롯 카드 5장 가로 → 키워드 칩 → 키워드 결과 점수순 리스트(키워드 없으면 `RECO.score` 키워드 없음 = 아무거나!). 도보 5분·10분 전체 목록 삭제(지도 칩·핀은 그대로)
  - 지금 충전소: 기본 정보 + 충전 시작(`charge.js`): 충전기 선택 → 현재/목표 % → 배터리(MY, 없으면 70kWh 가정) → 예상 시간 = (목표−현재)% × 용량 ÷ (출력 × 0.9), 급속은 80% 넘는 구간 출력 절반(가정) → 타이머(일시정지·종료, localStorage `chaeviCharge`로 새로고침 유지), 지도 위 작은 배지

  - 서울 급속 상위 3곳 기준(259곳 좌표 × 5 × 30·45 × 0~23시 중 2곳 이상인 60,960 상황): fit 기준 3곳 동점 53,543(87.8%) → fit2 기준 102(0.17%). 예전 안내가 틀리게 뜰 상황 53,441
